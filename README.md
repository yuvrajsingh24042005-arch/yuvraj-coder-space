# Yuvraj Singh Portfolio

Create a modern, professional personal portfolio website for a BTech Computer Science student named Yuvraj Singh.

The website should have a premium developer-focused design with a clean dark theme, subtle gradients, smooth animations, glassmorphism elements, and excellent spacing.

Build the following sections:

1. NAVBAR

- Logo/text: "YUVRAJ"

- Navigation links:

  Home

  About

  Skills

  Coding Profiles

  Projects

  Achievements

  Contact

- Sticky navbar

- Smooth scrolling

- Mobile responsive hamburger menu

2. HERO SECTION

- Large heading:

  "Hi, I'm Yuvraj Singh"

- Subtitle:

  "BTech CSE Student | Java Developer | Problem Solver"

- Short introduction describing me as a computer science student interested in software development, Java, DSA and web development.

- Two buttons:

  "View My Projects"

  "View GitHub"

- Add attractive developer-themed visual elements on the right side.

- Include subtle entrance animations.

3. ABOUT SECTION

Create a short professional introduction about Yuvraj Singh as a BTech CSE student who is learning Java, Data Structures & Algorithms, web development and software engineering.

Keep the content editable.

4. SKILLS SECTION

Create attractive skill cards for:

- Java

- C

- HTML

- CSS

- JavaScript

- SQL

- Git

- GitHub

- Data Structures & Algorithms

5. CODING PROFILES SECTION

Create three large professional cards:

- LeetCode

- GitHub

- CodeChef

Each card should contain:

- Platform name

- Short description

- Icon

- Profile statistics area with placeholder values

- "View Profile" button

Make the profile URLs and statistics easy to edit later.

6. PROJECTS SECTION

Create 3 modern project cards with placeholder projects.

Each card should contain:

- Project name

- Description

- Technologies used

- GitHub button

- Live Demo button

7. ACHIEVEMENTS SECTION

Create an attractive section for coding achievements, certifications and milestones.

Use editable placeholder content.

8. CONTACT SECTION

Include:

- Email

- GitHub

- LinkedIn

- A simple contact form

9. FOOTER

Include:

"© 2026 Yuvraj Singh. All rights reserved."

DESIGN REQUIREMENTS:

- Premium modern developer portfolio

- Dark professional theme

- Responsive on desktop, tablet and mobile

- Smooth scrolling

- Subtle hover animations

- Modern typography

- Clean cards

- Avoid excessive animations

- Avoid unnecessary stock images

- Make the website look like a professional software developer portfolio rather than a generic student template.

IMPORTANT:

Do not add fake personal achievements, fake statistics, fake companies or fake work experience.

Use clearly marked placeholders wherever real information is required.

Make all important text, links and profile information easy to edit later.
